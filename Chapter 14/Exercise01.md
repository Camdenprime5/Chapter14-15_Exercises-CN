# Chapter 14 - Exercise 01

## What is the difference between a class and a type?

A class is a programmer-defined type. It acts like a blueprint for creating objects. In Python, defining a class also creates a new type.

## What is the difference between an object and an instance?

An object is a value in Python. An instance is an object that belongs to a particular class.

## What is the difference between a variable and an attribute?

A variable is a name that refers to a value. An attribute is a variable that belongs to an object and is accessed with dot notation.

## What are the pros and cons of pure functions compared to impure functions?

A pure function does not modify its arguments or cause other side effects. Pure functions are usually easier to test and debug. An impure function can modify an object or cause another side effect, which can sometimes be convenient or efficient but can make a program harder to follow.

## What format specifiers can be used in a Python f-string?

F-strings can use format specifiers to control how values are displayed. Examples include `02d` for a two-digit integer with a leading zero, `.2f` for two decimal places, `,` for thousands separators, and `<`, `>`, or `^` for alignment.
